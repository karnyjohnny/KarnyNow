# docs/archive — frozen historical documents

Nothing in this directory is updated any more. These files record the
reasoning trail of rounds 0–XXXVIII. For the CURRENT state read
[`/START-HERE.md`](../../START-HERE.md) (the living handoff); for the current
per-round delta read [`/docs/INTEGRATION.md`](../INTEGRATION.md).

| File | What it is |
|---|---|
| `PROJECT-STATE.md` | the rounds I–XXXVIII session log — the deepest record of *why* things are the way they are (superseded as the handoff by `START-HERE.md`). **Its "Bootstrapping a NEW agent session" section is still useful**: clone URLs, the vendor-staging recipe, sandbox toolchain notes. |
| `HANDOFF.md` | the original research journal (Polish, frozen) — why the early decisions were made. |
| `AGENT-HANDOFF.md` | the round-IX recovery document (frozen); historical only. |
| `analiza/` | the round 0–3 feasibility/measurement analyses (Polish). `04-NVST-SPEC-BINARIA.md` is the byte-level NVST specification (20 pitfalls with symptoms); `05-PRZEGLAD-KODU-LOGOWANIA.md` the code review that became R22–R24. |

Path references inside these documents describe the repo layout **as it was
at the time** (root-level MDs, `src/`, `analiza/`, `tools_*.sh`); the layout
was reorganized in round XXXIX — see `docs/INTEGRATION.md` rev 29.
